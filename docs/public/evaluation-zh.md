# 评测记录：对白归属与语音（2026-09-16 至 17）

这份记录汇总 VoxStage 在两条线上做过的测量：**对白归属**（小说里每句对白是谁说的）和**语音**（克隆模型与引擎的盲听）。所有数字都是在一台 32 GB 内存的 Apple Silicon Mac 上实际跑出来的（已实测）；没有测过的地方写明「没测」。测试用的文本、打分口径和局限写在前面，结论写在后面，读者可以按同样的口径复跑（`scripts/attribution_matrix.py`、`scripts/listening_pairs.py`）。

**网络小说**：从网上找来的网络小说，因版权问题不适合公开，只在测试的电脑上用，内容不进入仓库，也不出现在任何公开材料里；这里只报句数和分数。网络小说二含有敏感内容，专门用来检验一个模型会不会因为内容而不认真回答——这是这类工具在实际稿件上的常见失败方式，公开文本测不出来。

## 二、打分口径

一段文本先切成单元（引号切，或按行切），模型给每个单元标「对白/旁白」和说话人，程序再叠加规则（叙述点名、自报家门、一来一往等）。评测把页面最终呈现给复核者的结果与作者确认的标签比较：

- **要改** = 复核者必须动手的句数：点错的名字 + 黄色（程序提示不确定）但错的 + 橙色（留空）+ 对白/旁白判错。这是唯一的主指标——它就是用户的工作量。
- 程序自己起的占位名（众人、某人甲）或作者没用过的称呼（短衣帮），只要一次改名就能对上作者的名字，算对：复核页上改一次名会带着所有句子。
- 每个模型单独跑整条流水线，评测里不许中途换模型兜底（产品里允许）。

## 三、对白归属：模型对比

同一提示词、同一 JSON 约束、同一规则，只换模型。数字是「要改」的句数，越小越好。

**六个模型、六段文本（9-16，规则改动前）**

| 模型 | 要改合计（215 句） | 每段用时 |
|---|---:|---|
| Qwen3-4B-Instruct-2507 Q8（默认） | 54 | 21–53 秒 |
| Qwen3-4B 去审查版 Q8 | 28 | 22–86 秒 |
| Qwen3.5-9B 普通版 Q5_K_M | 57（一段交白卷） | 89–152 秒 |
| Qwen3.5-9B 去审查版 Q5_K_M | 47（一段交白卷） | 92–158 秒 |
| **Qwen3-14B Q4_K_M** | **16** | 50–121 秒 |
| Qwen3-14B 去审查版 v2 Q4_K_M | 30 | 50–122 秒 |

**规则退为校验（9-17）**：把 14B 在冻结的十一段文本上的原始答案存下来，只重跑规则，逐条计量每条规则的得失。定下的关系：叙述点名、自报家门、多段引语的接续是强证据，可以改模型的名字；代词所指、语气像男像女是弱证据，只提醒不改名；模型留空的句子先按一来一往填上。结果：**十一段文本要改 38 → 13**，盲测章不变（2 → 2）。

**14B 与 30B-A3B 在十一段文本上（9-17，新规则）**

| 文本 | Qwen3-14B | Qwen3-30B-A3B（Instruct-2507，Q4_K_M） | 30B-A3B 去审查版 |
|---|---:|---:|---:|
| 阿Q 第 2 / 7 / 6 / 4 / 5 章 | 0 / 0 / 2 / 0 / 0 | 1 / 1 / 1 / 0 / 2 | 0 / 3 / 0 / 4 / 2 |
| 风波 | 1 | **0** | 7 |
| 傲慢与偏见（节选） | 0 | 1 | 2 |
| 孔乙己 | 3 | **0** | 4 |
| 网络小说一 | 2 | 9 | 2 |
| 网络小说二 | 3 | **47** | 46 |
| 盲测（阿Q 第 9 章前半） | 2 | 1 | 2 |
| **合计** | **13** | 63 | 72 |
| 每段用时 | 39–124 秒 | **22–60 秒** | 28–116 秒 |

读法：30B-A3B（混合专家，激活 3B）在公开文本上最好也最快；在网络小说二上塌了——70 句答成「没把握」，去审查版也一样，说明不是内容审查，而是这个模型对那段长文本本身拿不准。14B 在网络小说上稳。

**由此定下的产品行为**：机器启动时按内存和已安装情况取 30B-A3B → 14B → 4B 里第一个装得下且装了的；所选模型交白卷（放下的句子不到一半）时依次换 14B、4B 去审查版重来一次。两个 9B、两个去审查版大模型在测完后删除（作者决定）。

## 四、语音：盲听

方法：同一句、同一声线、同一随机种子，只换模型或引擎出两版，甲/乙顺序随机，答案表由协作的 AI 保管，作者只说「效果好的是哪一个」。样本很小（一个人听、每轮 4–6 句），只用于定方向，不用于声称「全面更好」。

**克隆模型 0.6B 对 1.7B（Qwen3-TTS Base；六句，作者先标出不满意的句子）**

| 声线类型 | 1.7B 被选 |
|---|---|
| 固定/自定义声线（克隆） | 3 / 3（一句只是稍好） |
| 预设音色 | 2 / 3 |

克隆每句用时 5–9 秒 → 9–15 秒。**决定**：装了 1.7B 克隆模型的机器，新工程默认用它；旧工程保持原样，可一键切换。

**克隆引擎：Qwen 1.7B Base 对 Chatterbox Multilingual v3、对 IndexTTS 1.5（各 4 句）**

| 对比 | Qwen 被选 | 备注 |
|---|---|---|
| 对 Chatterbox v3（MIT，mlx-audio 移植） | 3 / 4 | 每句 3–6 秒 |
| 对 IndexTTS 1.5（Apache-2.0，mlx-audio 移植） | 4 / 4 | 漏读；文本里写拼音定读音也不准 |

**决定**：克隆路线留在 Qwen；两个引擎连同权重删除。四声等生僻读音仍无解，等有可靠拼音/音素控制的引擎。

**省略号停顿**：两种克隆模型都不会在「……」处停顿。试了把省略号改成逗号/句号/破折号（机器量到的停顿差别小）和「在省略号处拆句分别朗读、中间插静音」两种停法；作者选了拆句 + 半秒。做成工程设置，新工程默认开。

## 五、局限

- 标签由一个人确认，盲测章由 AI 标、作者抽查；不同读者对「引述还是对白」有分歧（例如叙述里的短引号、拖尾的省略号）。
- 盲听只有一个人、每轮 4–6 句；引擎对比只用了自定义声线，没有测预设音色。
- 所有用时都含模型加载，取决于机器；本记录的机器是 32 GB 内存。
- 网络小说不公开，所以它们上面的分数无法由他人复核；公开文本上的可以。
