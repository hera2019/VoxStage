# 第一次试用

这是可运行的开发预览。本轮已试听的 60 字以内样本获本人认可；新稿件仍请试听。

1. 在项目文件夹双击 `Start VoxStage.command`。程序自检后会自动打开浏览器，请保留原启动终端窗口。
2. 若浏览器未自动打开，可访问 http://127.0.0.1:8765。重复双击启动会打开已运行的同一工作台。
3. 选择“雨夜 · 中文实测”或“A rainy evening · English test”。已有本机生成的四句样例。
4. 点每句右侧试听，检查有没有读错、漏字、角色声音是否合适。点击“导出作品”可下载完整音频、句级字幕和时间轴。
5. 点击一句编辑正文，明确点击“保存修改”，再生成待处理句子。其它句子的已有音频会复用。也可撤销，或只为该句生成新版本。
6. 要试自己的短稿，点“新建工程”。每行写“角色：一句台词”；英文同样支持冒号。目前先控制为短篇，中文每行最多 60 字符、英文 240 字符。

工程与声音保存在项目内 `user-data/projects/`。第一次安装需下载约 2.5 GB 模型；本机已备好，日常生成走本地。退出服务请在启动终端按 Ctrl+C；运行中取消生成会等当前句完成。

## 这次需要你验收什么

先试听中文、英文各四句：记录读错或漏掉的句子，角色是否容易分辨、语气是否自然、字幕出现和消失是否合适。能生成文件不等于这些指标已经通过。

当前已支持固定合成角色声线和本地文字检查；尚无自动识别小说说话人、真人录音克隆或手机连接。手机不能靠打开自己的 localhost 地址连接 Mac；家庭网络配对属于后续工作。

## 固定同一个角色的声线

先生成并试听一句，满意后选中该句，点击右侧“固定为此角色声线”。随后生成待处理句子，这个角色的其它台词都会参照同一声音；编辑和单句重做也会沿用。原参考文件独立保存，不随正文修改而改变。

要恢复预设声音，点“解除固定声线”，或使用撤销。改变该角色的音色也会解除固定；其它角色不受影响。请先用“固定声线 · 英文集成”工程试用；旁白已固定，另两个角色保持预设。其新生成结果仍请你试听确认。

当前固定功能只接受本软件已生成的预设合成音，不接收真人录音。其参考文件随工程保存在 references 子目录，备份请保留整个工程目录。本机已经备好固定声线模型，另一台电脑还需要安装 Base 模型。

## 检查声音有没有读完整

生成声音后，点击“检查已生成声音”，或选中一句点“检查这句声音”。程序在本机把声音转成文字；如果填写了朗读文本，就按朗读文本核对。

点击“文字待复核”的句子，右侧会显示核对文本、识别文字和差异。试听后，确实没有读错时再点“我已试听，确认无误”；若有问题，可修改朗读文本或生成新版本，然后重新检查。未发现文字差异不等于音质或发音已通过。

检查会保存到工程。修改、换声线或重做后，旧结果显示“文字需重查”。可以停止批量检查，当前一句处理结束后停止。导出作品时会附带文字检查报告，保留未检查、可疑和人工确认的状态。

现成样例“回读检查 · 中文”和“回读检查 · English”可以查看结果；英文 Leo 的 the/a 差异需你听辨，不能仅凭识别结果判定漏读。

## 启动遇到问题时

双击项目里的 `Check VoxStage.command`。它只检查环境，不下载模型、不生成声音；结果保留在窗口中，按回车关闭。需要排查时查看提示的环境报告文件，报告不包含稿件或录音。

| 提示 | 怎么处理 |
|---|---|
| 尚未建立 Python 环境 | 按 README 的首次安装步骤设置 Python 3.12 和项目独立环境。 |
| 运行依赖无法载入 | 按 README 安装锁定版本依赖；详细错误保存在本地报告。 |
| 缺少网页文件 | 在 frontend 目录安装前端依赖并构建，具体命令见 README。 |
| 某个模型未备齐 | 按 README 安装对应模型。可以先编辑稿件；已备齐的其它功能仍可使用。 |
| 模型记录或识别设置损坏 | 按 README 重新运行对应模型设置脚本；程序不会直接删除配置或用户工程。 |
| 端口已占用、无法确认服务 | 如果是旧版 VoxStage，先完成任务，再到原启动窗口按 Ctrl+C 关闭后重试；不要随意终止其它程序。 |
| 启动未完成或服务退出 | 查看窗口提示的本地启动日志，保留日志供排查。 |

停止时在原启动窗口按 Ctrl+C。已保存的稿件和音频仍在；尚未完成的一句可能需要下次重新生成。再次双击启动即可恢复工作台。

自检只验证启动条件及关键文件是否在位，不能代替模型首次载入、声音生成和人耳验收。当前仍是开发预览的设置步骤，尚未提供签名安装包或全新 Mac 一键安装。

## 听到尾音或声音异常时

选中那一句，点击“标记声音问题”，选择问题类型并填写可选备注。标记保存在工程里，文字检查即使显示一致，也不会替你清除人工问题。

可以直接为这一句生成新版本，或点“重做标记的句子”集中处理。批量操作只重做当前有问题标记的声音；取消时当前一句先结束，其余句子保留原声音和标记。

生成新版本后显示“新版本待试听”。重新试听确认问题已解决，再清除问题标记；若仍有问题，可以给新版本重新标记。旧问题记录和旧音频都会保留，清除标记可撤销。导出的“检查与听稿报告”包含自动文字检查和人工问题记录。

独立示例“听稿标错 · 验证样例”用于验证操作，其中的备注明确写着“流程验证用标记”，不代表已经发现实际声音异常。

## 整理工程

工程标题旁可“改名”或“归档”。归档不删除任何稿件和声音；在“查看归档工程”中打开后可以“恢复工程”。改名和归档都能撤销，声音无需重新生成。

窄屏侧栏隐藏时，页面上方的“切换工程”可以选择已有工程，包括归档工程。该控件不代表已经开放手机连接 Mac；目前仍只在本机访问。

换电脑的步骤见 [环境与模型准备](setup-zh.md)。

## 语速偏慢与同音字提示

右侧“作品语速”可选原速、1.1、1.2 或 1.3 倍，作用于整份作品的试听和导出。可以先试 1.2 倍，原始声音保留，不需要重新跑语音模型。字幕按变速后的成品重新计算。听稿和导出由不同方式变速，成品仍请试听。

“语速与同音复核 · 试用”是独立样例，包含本人指出的小雪那一句，已设为 1.2 倍。原工程保持原样。

中文检查会兼容部分同音写法，比如常见助词的、地、得，以及推断为同声调读音的字；右侧显示兼容了哪些字，原始识别文字保留。词语中读音不同的“土地、目的、得意”等常见情况继续保护，多音词判断仍可能出错。旧版检查会显示需重查，点“检查这句声音”即可更新。

句内突然断开与“句间停顿”不是同一个设置。目前句内节奏异常仍可标记并单句重做；本轮没有自动裁切正常停顿。加速也会缩短停顿的播放时间，但不会保证修好语气或分句。

## 同一句前后语速不同

选中已生成句子，在“声音时间线”拖选后半句，调速度后点“应用选区速度”。也可输入原音开始/结束秒数。已保存范围点“调整”可再次修改；试听选区前要先保存设置。局部速度范围 0.5–2.0 倍，直接覆盖该范围的作品速度。

橙色可疑停顿可点击试听原音附近；“对照原音”与“试听调整后整句”便于比较。原音不变，重新生成后旧选区停用。调整不能自动解决所有不自然发音。详细检查点及当前漏检见 [声音复核](audio-review.md)。
