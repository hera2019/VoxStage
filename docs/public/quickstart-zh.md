# 第一次试用

这是可运行的开发预览。三个样例（`examples/`）都是用下面这条流程做出来的；新稿件仍请试听。

## 从一段小说到一段多声部录音

1. 在项目文件夹双击 `Start VoxStage.command`。程序自检后会自动打开浏览器；请保留启动终端窗口。
   若浏览器未自动打开，可访问 http://127.0.0.1:8765。
2. 点「＋ 新建工程」，把**没有标注角色的原文**直接贴进去（3000 字以内）。按钮会自动变成
   「分角色并创建工程」：本机模型先给每段标上旁白/对白和说话人，然后交给你复核。
   - 已经写成「角色：台词」每行一句的剧本也可以直接导入（[格式说明](script-format.md)，英文）。
   - **超过 3000 字**（比如整本小说）会被整理成一本「书」，按「第X章」或「Chapter 3」这样的章节标题切开，
     没有标题就按段落切；对白特别密的一章（超过草稿一次能接的 80 个引号切片）会在段落末再切几段。
     从任意一章开始建工程。章节工程顶上会显示「《书名》第 N 章 · 共 M 章」和「下一章 →」，
     下一章的工程自动沿用上一章的设置（同名角色的声音、固定声线、词典、模型、停顿、语速），一本书只配置一次；
     前面章节确认过的角色名会作为候选出现。
3. **复核角色草稿**：把说话人对上就够了。模型没把握的对白留空，两个人一来一往时会给出建议，
   点「用『某某』」采纳。拆分、合并、改字、不朗读，进了工程之后在编辑页里都能做。
4. 工程建好后先看**角色音色**：每个角色一个声音。声音不够用就点「音色试听」→「设计一个新声线」，
   用一句话描述（年龄、性别、嗓音、语气），听一句；同一段描述每点一次出一版不同的声音（留 8 版可比），
   选中满意的那版起名保存；之后角色直接选它。
5. **生成与检查**：生成待处理句子；然后「检查已生成声音」——每句会被转写回文字和台词比对，
   念错、漏字会标出来；时长异常（念完接着念）也会标出来并已自动重做一次。
6. **句子**页签里调整单句：改字、拆分（把光标放在要断开的位置）、并入上一句/下一句、删除、
   不朗读（保留在剧本里但不进录音）、生成新语音、本句之后的停顿。
7. **导出作品**：完整音频、字幕（按语音停顿切、已去掉引号和句末的句号逗号，保留！？）、时间轴、
   剪辑交付包（逐句音频 + 表格，可整体搬走）、以及给 DaVinci Resolve / Premiere 的 XML 时间线。

## 值得知道的几个设置

- **预设音色模型**（整个作品）：新工程默认 1.7B，音质更好；16 GB 内存的机器选 0.6B。
- **发音词典**（整个作品）：「写法→读法」，一行一条，例如 `偸→偷`。只影响念法，不改正文和字幕；
  改一条只有含这个字的句子需要重新生成。
- **朗读文本**（这一句）：只改这一句念什么，正文和字幕照旧。
- **多音字定读音**：写成 `干[gan4]` 或 `干[gàn]`，朗读文本和词典里都能用（`干活→干[gan4]活`）。
  程序会换成一个只读这个音的常用字（这里是「赣」）交给声音去念；正文和字幕仍是「干」，面板上会显示实际念的字。
- 所有修改都能撤销；已生成的音频不会因为改别的句子而丢失。

工程、书和声音都保存在项目内 `user-data/`，不上传、不进版本库。退出服务请在启动终端按 Ctrl+C。

## 这次需要你验收什么

试听是程序替不了的：角色是否容易分辨、语气是否自然、字幕出现和消失是否合适、合并后的句子是否顺。
程序能证明的只有「念的字对不对」和「有没有多念」；能生成文件不等于这些指标已经通过。

## 边界

固定声线与音色库只接受本软件生成的合成音，或**你拥有使用权并明确确认**的录音；生成的声音都标注为合成语音，
不得用于冒充他人。手机不能靠打开自己的 localhost 地址连接 Mac。
