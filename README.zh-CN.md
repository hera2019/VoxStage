# VoxStage

面向 Apple Silicon Mac 的本地脚本配音工作台。把标好角色的剧本变成逐句音频——可试听、可重做、可导出，**原文保证不被改写**。

> **开发预览版。**整条流程已经跑通，但这不是发布版产品，而且有一项质量标准**明确未通过**——见[当前未通过的质量问题](#当前未通过的质量问题)。

## 它做什么

给它一份每行是 `角色：台词` 的剧本：

```
旁白：雨点轻轻敲着窗。
小林：你听见了吗？
阿宁：别担心，那只是风。
```

给每个角色选一个声音，生成，然后逐句工作——试听、重做不满意的、调整节奏、导出。中文和英文目前都支持。

产出：一个 WAV、一份**按实际音频采样数**生成的 SRT 字幕，以及一份内容核对报告。

## 为什么不直接用现成的 TTS 工具

四条特性，每一条都是刻意的设计取舍，不是功能堆砌：

**你的原文永远不会被改写。**分析和检查只能**标注**文本，只有你能改动它。朗读调整（数字、缩写怎么念）放在单独字段里，所以字幕保留你写的原话。

**改一句，只重做一句。**每个句段有稳定身份和生成指纹，指纹覆盖真正送给引擎的文本、声音和参数。改第 400 句里的第 40 句，其余 399 个音频文件原封不动——这是**比对字节和修改时间验证过的**，不是假设。

**生成的语音会被转写回来，与原文比对。**语音合成可能在听感完全自然的情况下漏字——[我们实测到一段文本被无声漏掉 17%](#这个产品是怎么来的)。所以成品音频会在本地转写，与应该说的话逐句比对。发现差异只做标记提示你去听，**绝不自动修改**。

**没有任何东西离开这台机器。**模型在本机 Apple Silicon 上运行。没有账号、没有云端生成、不按字数计费、不上传你的剧本和音频。

## 快速开始

在配置好的 Mac 上双击 **Start VoxStage.command**。用 **Check VoxStage.command** 查看环境报告，它不下载任何东西。

## 当前未通过的质量问题

**同一角色跨句音色一致性没有通过试听。**同一个旁白角色的两句话，被判断为音色和空间感不够一致。仅仅固定预设 ID 和随机种子是不够的，波形指标一致也不满足这条标准。

这是当前的首要问题，**比上面任何一项功能都重要**：一个多角色朗读作品能不能用，取决于角色在第 300 句时听起来还是不是同一个人。这条记录在 [`acceptance.md`](docs/public/acceptance.md) 里，**没有被宣称为已完成**。

## 这个产品是怎么来的

VoxStage 源于一次本地模型研究中发现的具体故障：一段声音克隆自然、可辨认地读完了全文，却**无声地跳过了中间 40 个字**。没有人能听出来——因为跳过之后读出的仍是一句通顺的话。

两条设计规则由此直接得出，并且都在产品里：

- **逐句生成。**跳句发生在长文本一次性生成；短句段同时带来逐句缓存和字幕时间粒度。
- **转写回读比对。**静默失败无法靠试听发现，只有一个**能与结果唱反调**的检查才找得到它。

完整记录：[AI-Lab / 声音克隆核验](https://github.com/hera2019/AI-Lab/blob/main/qwen3-tts-0.6b-voice-clone-mlx/results/phase-1-iphone-repeat-verification.md)

## 自动分角色：测过了，但没上产品

对没有标注的小说文本，本地模型可以提出谁在说话。在 20 个自写中英文场景上比较了两个本地模型，流程中**原文由程序恢复，不由模型抄写**：

| | Qwen3 4B Q8 | Qwen2.5 1.5B Q4 |
|---|---:|---:|
| 原文完整保留（程序保证） | 20/20 | 20/20 |
| 明确对白角色正确 | 34/40 | 15/40 |
| 歧义对白正确标为 UNKNOWN | 4/4 | 1/4 |
| **整个场景全部标签正确** | **8/20** | 1/20 |

**最后一行才是决定产品形态的那个数字。约 60% 的场景需要人工修改**，所以自动分角色只能作为**可编辑的草稿**交给人审核，绝不做无人值守的批量生成。20/20 的原文保留是程序规则的功劳，不是模型的。

参考答案由助手在模型运行前拟定，尚未经独立人工复核；20 个场景中有 16 个在更早的基线里出现过。**这是用于工程选型的证据，不是泛化能力的结论。**

语料、提示词与评分：[`evals/speaker_attribution/`](evals/speaker_attribution/) · 结果：[`results/speaker-attribution-summary.md`](results/speaker-attribution-summary.md)

## 限制

- 角色由你提供，自动分角色尚未接入。
- 预设音色，加上由模型自己生成的固定参考。**不提供上传真人参考音的通道，这是设计决定。**
- 字幕使用基于能量的语音边界估计，需要人工复核，**不是强制对齐**。
- 峰值归一化，不是响度标准合规。
- 取消在句间生效，当前正在生成的句子会完成。
- 仅限 Mac。没有局域网配对、移动端接入、安装包签名和更新机制。
- 内容核对忽略普通标点和大小写，但保留否定、数字和有意义的符号。同音字和数字读法差异会造成误报。**不宣称任何准确率**——没有测过。

## 伦理

- 不存在上传真人参考音的通道。固定角色声线由模型自己的合成输出构建，保存时带校验和与生成它的文本。
- 生成音频不冒充真人。
- 你提供的剧本，其内容权利由你自己负责。
